# 📸 نظام الرد الآلي على انستغرام والرسائل الخاصة (Instagram Auto-Reply & DM Automation)

نظام متكامل واحترافي موجه لأصحاب المتاجر والشركات لإدارة والرد التلقائي على تعليقات انستغرام، العمل التلقائي للايك، وإرسال الرسائل الخاصة (Direct Messages) للمُعلقين وفق كلمات مفتاحية أو ردود ثابته.

---

## 🌟 مميزات النظام التجاري

- 🚀 **الرد الآلي الثلاثي**: لايك تلقائي + رد عام تحت التعليق + رسالة خاصة فورية (DM).
- 🌟 **الرد الثابت العام**: إمكانية الرد بعبارة ثابتة على كافة التعليقات.
- 🎬 **تخصيص المنشورات والريلز**: إمكانية تخصيص رد ورسالة خاصة فريدة لكل ريلز أو منشور برابطه/معرفه.
- ❤️ **وضع الإعجاب فقط (Like Only)**: تفعيل الإعجاب التلقائي بدون رد أو DM لبعض القواعد.
- 🧪 **المحاكي التفاعلي الحي**: تجربة واستعراض الردود حياً داخل لوحة التحكم.
- 📊 **تحليلات وسجلات المبيعات**: متابعة الكلمات الأكثر طلباً وسجل التعليقات.

---

## 🚀 طريقة التشغيل للعملاء (بنقرة واحدة)

### لمستخدمي نظام الويندوز:
فقط اضغط مرتين على الملف: **`start.bat`**
سيقوم النظام تلقائياً بتثبيت المتطلبات وفتح لوحة التحكم في المتصفح على الرابط:
👉 `http://localhost:3000`

### التشغيل عبر الأوامر (Terminal):
```bash
npm install
npm start
```
